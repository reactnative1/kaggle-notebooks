# 🎭 Tencent MimicMotion (Headless Batch)

Tencent MimicMotion generates temporally smooth human motion videos from a reference portrait image and a driving pose video using confidence-aware pose guidance.

* **Accelerator:** Kaggle Dual Nvidia Tesla T4 GPU (or P100)
* **Mode:** **Headless Batch**

## 🚀 How to Run
```bash
python tools/push_kernel.py runners/tencent-mimicmotion_headless_mode --profile my_profile
```
